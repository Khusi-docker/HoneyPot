Ollama Error

Something went wrong while processing your request.

1. Check server connection

Ensure the Ollama server is reachable and the port is open.

2. Verify API Key

Confirm the key exists, is valid, and not expired.

3. Validate model name

Check for typos or unavailable models.

4. Rate limits

Ensure your request quota is not exhausted.

5. Payload format

Large or malformed JSON prompts may fail.

6. Read logs

Inspect the server logs for detailed errors.

Include the full error text when reporting — it speeds up fixes.
